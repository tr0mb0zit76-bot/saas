# Инструкция для админа тенанта: запуск работы в Traklo Pro

Краткая памятка после того, как платформа выдала вам кабинет (поддомен вида `https://ваш-slug.crm.example.com`).

## 1. Первый вход

1. Откройте ссылку кабинета (поддомен вашей компании).
2. Войдите логином/паролем, которые прислал оператор платформы (или завершите мастер онбординга, если он открылся).
3. Рекомендуется сразу сменить пароль в профиле.

## 2. Онбординг компании (если мастер ещё не пройден)

1. Укажите название компании и часовой пояс.
2. Добавьте **свою компанию** (юрлицо) — ИНН, адреса, банк, подписант. Это нужно для печати и реквизитов.
3. Пригласите сотрудников (если доступно в настройках ролей) или попросите оператора платформы создать пользователей.

## 3. Роли и доступ

1. **Настройки → Администрирование → Роли** — проверьте, что у менеджеров есть области: лиды, заказы, контрагенты, задачи.
2. Модули тарифа **Про** (печать, почта, график оплат и т.д.) появляются в меню только если они включены в план. На тарифе **Старт** печати в меню нет.

## 4. Контрагенты и первый заказ

1. **Контрагенты** — заведите заказчика и перевозчика (хотя бы по одному).
2. **Лиды** — создайте лид и при необходимости конвертируйте в заказ.
3. **Заказы** — заполните маршрут, ставки, стороны. Сохраните.

## 5. Печатные формы (тариф Про и выше)

Готовых DOCX продукт **не подкладывает** — загружаете свои макеты.

1. **Настройки → Конфигурация → Шаблоны**.
2. Кнопка **Справочник плейсхолдеров** — список полей заказа/лида.
3. Вкладка **Свои плейсхолдеры** — короткие имена для Word; сопоставление **только из списка** справочника (например макрос `nomer_klienta` → `customer.inn`).
4. **Добавить шаблон** — загрузите DOCX с макросами `${...}` или `{{...}}`.
5. На карточке шаблона проверьте вкладку плейсхолдеров и при необходимости поправьте сопоставления.
6. Откройте заказ → сформируйте черновик документа по шаблону. Для PDF-превью на сервере должен быть доступен Gotenberg (это зона платформы).

## 6. Документы и оплаты (Про)

1. Раздел **Документы** — реестр файлов по заказам (колонки «1С» / ЭТрН на обычных пилотах скрыты).
2. **График оплат** — если включён в тариф.

## 7. Почта и MCP (если включены)

- **Почта** — настройки IMAP задаёт платформа/админ по runbook; в кабинете синхронизация писем.
- **Связи MCP** — для текстового помощника (чтение); токены выпускает пользователь с правом настроек.

## 8. Внешний вид

**Профиль / Внешний вид** — тема и skin (в т.ч. Traklo). Настройки сохраняются на сервере.

## 9. Если что-то недоступно

| Симптом | Что проверить |
| --- | --- |
| Нет пункта «Шаблоны» | Тариф без модуля печати (`print`) — нужен Про |
| 403 на раздел | Роль / visibility area |
| Макрос в DOCX пустой | Есть ли путь в справочнике; своё имя заведено на вкладке «Свои плейсхолдеры» |
| PDF не открывается | Сообщите оператору платформы (Gotenberg) |

## 10. Чего ждать не стоит на пилоте

- Синхронизация с «вашей» 1С «из коробки» — не входит; при необходимости делается **отдельный Enterprise-адаптер** под вашу систему.
- Готовые файлы заявок/счетов от вендора — загружаете свои DOCX.
- Биллинг/оплата подписки — пилоты бесплатные; счета выставляет оператор платформы отдельно, когда появится коммерция.
