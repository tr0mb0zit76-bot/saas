## 0. Что продаём

| Контур | Репозиторий | Формат | Кому |
| --- | --- | --- | --- |
| **Traklo Pro SaaS** | `saas.git` | подписка, `{slug}.traklo.pro` | экспедиторы 5–50, облако |

**Ценность для клиента (якорь переговоров):** хаос Excel/почта ≈ **0,5–1 FTE** (порядок **40–60 тыс ₽/мес**). Подписка Про ~40–60% этой экономии.

## 3. On‑prem / «на свой сервер» — оценка продукта

### 3.1. Как считать лицензию

Практичный якорь для vertical B2B в РФ:

| Модель | Формула | Когда |
| --- | --- | --- |
| **A. Perpetual (разово)** | **18–30×** месячного SaaS-эквивалента того же пакета | «купили и забыли», редкие апдейты |
| **B. Annual on‑prem** | **10–14×** мес. SaaS (= ~год облака ±) | хотят обновления без «вечной» лицензии |
| **C. Hybrid** | разово **12–18×** + ежегодная поддержка **18–25%** от лицензии | самый частый B2B |

Ориентиры рынка «коробка/сервер»: Falcon-подобные от ~170 тыс разово; 1С:TMS от ~120 тыс база + клиентские + внедрение. Наш продукт шире «голого TMS» (CRM + оплаты + печать + мобильный контур) → **не демпинговать до нижней полки 1С**.

### 3.2. Рекомендуемый list — лицензия «как есть» (без внедрения)

Состав «как есть» = код релиза + миграции + runbook установки + 1 окружение (staging|prod). Без кастома, без интеграции 1С/ЭДО «под ключ», без переноса данных.

| Пакет on‑prem | Соответствие SaaS | Разовая лицензия (list) | Или год on‑prem |
| --- | --- | --- | --- |
| **Старт** | Start features | **180–250 тыс ₽** | **110–140 тыс ₽/год** |
| **Про** (якорь) | Pro features | **450–650 тыс ₽** | **280–360 тыс ₽/год** |
| **Корпоративный** | Enterprise | **от 1,2–2,0 млн ₽** | **от 700 тыс – 1,1 млн ₽/год** |

**Рабочий якорь для КП:** Про on‑prem **550 тыс ₽** разово **или** **320 тыс ₽/год** (обновления minor+patch входят в год; major — по прайсу).

Мультифилиал / несколько юрлиц на одной инсталляции: **+30–100%** к лицензии или отдельный инстанс по прайсу.

### 3.4. Enterprise «в одни руки» (весь продукт одному покупателю)

Два разных смысла — не путать в КП:

| Смысл | Что получает покупатель | Мы можем продавать SaaS дальше? | List (ориентир) |
| --- | --- | --- | --- |
| **A. Полный Enterprise on‑prem одному клиенту** | Весь функционал Корп на *его* сервере, 1 инсталляция, без эксклюзива на рынок | Да | **1,5–2,5 млн ₽** разово (якорь **~2,0 млн**) + поддержка **18–25%/год** (~350–500 тыс) |
| **B. Эксклюзив «в одни руки»** | То же + исходники/репо + мы **не** продаём этот продукт конкурентам в оговорённой гео/вертикали (или freeze SaaS-пилотов) | Нет / сильно ограничено договором | **5–12 млн ₽** разово (якорь **~7–8 млн**) · или **3–5 млн** + роялти **5–8%** выручки покупателя от продукта 3–5 лет |
| **C. Продажа IP / бизнеса** | Все права, команда опционально | Мы выходим из продукта | От **15–40 млн+** (см. §6; не «лицензия Корп») |

**Почему A ≠ B:** в A клиент платит за *свой* контур (как дорогой 1С+внедрение). В B он выкупает *рыночную опцию* — мы теряем ARR SaaS и право масштабировать пилоты; цена ≈ несколько лет целевого ARR + премия за эксклюзив.

**В оферте B обязательно:** территория/отрасль эксклюзива, срок (или бессрочно), исключения (уже живые tenants), escrow исходников, запрет ресейла третьим экспедиторам без нашего согласия (если не полный assignment).

### 3.3. Что обязательно писать в оферте on‑prem

- Версия/релиз, ОС (Linux), PHP/MySQL/Redis, HTTPS, бэкапы — зона клиента  
- Нет multi-tenant «чужих» компаний на одном ключе без доплаты  
- Исходники: **escrow / доступ к репо** — отдельная строка (часто +20–40% к лицензии)  
- Репозиторий: не путать `v5` (AA) и `saas` — в договоре явное имя продукта и ветка/тег

## 4. Поддержка (после продажи)

| Уровень | Что входит | Цена |
| --- | --- | --- |
| **Базовая** | Баги в нашем коде, консультации по установке (email, SLA 2 раб. дня), патчи безопасности | **18–22%** от разовой лицензии / год · или **25–35%** от годовой on‑prem |
| **Стандарт** | + приоритет, remote-помощь, минорные обновления продукта | **22–28%** / год |
| **Премиум** | + N часов/мес, дежурство, выделенный канал | **от 40–80 тыс ₽/мес** фикс **или** % выше |

Для SaaS поддержка «в подписке»; для on‑prem **без оплаченной поддержки обновления не обещать**.

Минимум на Про on‑prem: **~100–150 тыс ₽/год** поддержки при лицензии ~550 тыс.

## 5. «Допиливание под себя» (кастом)

Не смешивать с лицензией: отдельный SOW / доп. соглашение.

### 5.1. Ставка

| Роль | Ориентир ₽ |
| --- | --- |
| Разработка (full-stack наш стек) | **4 500–7 500 / час** · пакетно **80–120 тыс / человеко‑день** |
| Аналитика / внедрение | **3 500–6 000 / час** |
| Срочность / вне очереди | **×1,3–1,5** |

### 5.2. Типовые пакеты (T&M с потолком или fixed)

| Работа | Оценка |
| --- | --- |
| Брендинг, печатные формы, роли, справочники | **80–250 тыс** |
| Импорт данных (контрагенты/заказы) | **150–400 тыс** |
| Интеграция «простая» (webhook, выгрузка) | **200–500 тыс** |
| Интеграция 1С / ЭДО / банк (коннектор) | **от 400 тыс – 1,5+ млн** |
| Доработка модуля «как у нас в Excel» | **от 300 тыс**, только после discovery |
| Discovery / аудит процессов (фикс) | **80–150 тыс** (зачитывается в проект при старте) |

### 5.3. Правила маржи

1. Кастом **не** входит в скидку на лицензию.  
2. Оценка только после discovery; fixed price — с буфером **+30–50%** на неопределённость.  
3. Код кастома: либо в **отдельном репо/пакете клиента**, либо платный merge в продукт (иначе вечный fork).  
4. Поддержка кастома: **+15–25%** стоимости кастома / год **или** отдельные часы.

## 6. Сводка «во сколько оценить продукт»

| Вопрос | Ответ (стартовый) |
| --- | --- |
| SaaS Про | **24 900 ₽/мес** (якорь продажи) |
| On‑prem Про «как есть» | **~550 тыс ₽** разово **или** **~320 тыс ₽/год** |
| Поддержка on‑prem | **~18–25%** лицензии / год (не ниже ~100 тыс на Про) |
| Допилка | **80–120 тыс / день** · типовые пакеты выше |
| Весь бизнес SaaS (грубо) | 20 платящих × ~22k → ARR ~5 млн; 50 × ~28k → ~17 млн |
| Exit «заплатите — я ушёл» | См. §6.1; **40 млн ₽** = верх коридора / стратегический потолок, не база при слабом ARR |

### 6.1. Продажа инвестору / стратегическому покупателю («я ушёл от дел»)

Это **не** раунд VC «деньги на рост», а **продажа актива** (код + IP + tenancy/platform + пилоты + домен/бренд). Покупатель сам крутит продукт.

| Линза | Что даёт | Ориентир |
| --- | --- | --- |
| **Стоимость замещения** | Сколько собрать такой vertical CRM с нуля (годы стека Laravel/Inertia + логистика + SaaS) | **~20–50 млн ₽** «в труде» → продавцу обычно **40–70%** (риск, docs, bus factor) |
| **Выручка** | Финансовый покупатель смотрит ARR × мультипликатор | При малом ARR — почти не цепляется; при ARR 5 млн → часто **2–5×**; при 15–20 млн → **3–6×** |
| **Стратег** (TMS/1С-партнёр/холдинг) | Экономит 1–2 года и покупает готовый контур | Готов платить ближе к замещению, если есть пилоты и чистый IP |
| **«Основатель уходит»** | Нет носителя домена в сделке | Скидка **-25–40%** vs «основатель остаётся на 6–12 мес transition» |

**Вердикт по «≈40 млн ₽» сейчас**

- Как **ask / потолок** в переговорах со стратегом при сильной демонстрации продукта, пилотах, чистом репо и transition 3–6 мес — **можно ставить 30–40 млн**, но закрытие чаще уйдёт ниже.
- Как **реалистичный close без ARR и без вашего оставания** — ближе к **12–25 млн ₽** (код+пилоты+домен), иначе покупатель считает «куплю команду и перепишу».
- **40 млн «и я сразу исчез»** — слабо: покупатель платит за риск bus factor; без earn-out / 3–6 мес сопровождения цена падает сильнее, чем кажется.

**Что поднимает цену к 40 млн:** 10+ платящих tenants, предсказуемый MRR, витрина/воронка живая, runbooks, тесты изоляции, отсутствие AA-only долга в продаваемом IP, вы согласны на transition + escrow.

**Структура сделки умнее «все 40 сразу»:** 50–70% на closing + 30–50% через 6–12 мес (earn-out по пилотам/ARR) + 3–6 мес paid transition отдельно.
